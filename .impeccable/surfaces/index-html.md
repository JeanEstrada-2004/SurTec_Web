## Direction contract

THESIS: The whole page is one living project network. A single persistent 3D graph changes topology with the story (ordered → severed and scattered → pulled into PROYECTO → modules in orbit → stable ecosystem). It refuses the category default of stacked feature sections with icon cards and a headline-over-button hero.

OWN-WORLD: The engineering drawing (plano) of a project-based company. Light phase is Blanco Técnico paper with a fine drafting grid, Gris Estructural ink and 1px technical strokes, node dots echoing the logo's network; the integrated phase is the same drawing in negative (cyanotype) on Azul Corporativo with Azul Integración signal lines. Components borrow drafting vocabulary: leader lines, dimension rulers for goals, a cajetín (title block) for credits. Montserrat (wordmark voice) for display, Archivo for text and labels, tabular numerals for data.

STORY: SurTec works by projects → its data lives in seven tools → consequences cascade → "¿Y si…?" → everything converges on PROYECTO → modules, flow, OCR, architecture → 2030 goals, roadmap and investment → the mockup, live, one click away.

FIRST VIEWPORT: Left 6/12: official color logo small, title "Transformación Digital para la Gestión Integral de Proyectos" at display scale, subtitle (platform name), line "Del dato aislado a la trazabilidad integral del proyecto.", primary action "Descubrir propuesta" and secondary "Explorar plataforma". Right and behind: the 3D field of isolated data nodes on the drafting grid, drifting in depth. Top bar: isotipo + PETI 2027–2030, persistent Explorar plataforma; right edge: 10-step progress rail.

FORM: User-pinned direction, no roll: the user approved the 10-scene proposal in conversation ("te dejo trabajar... con las animaciones que mencionaste"), and new-work allows a pinned direction to beat the roll. `concept-seed --check-seed none` printed "SEED NONE: this machine can make seed references, so a brief written here records one; `none` means the roll was skipped." seed: none (roll skipped: user-pinned)

Signature interaction: scroll scrubs the network's topology; in scene 5 modules are focusable/hoverable for a two-line spec; scene 6 a data pulse travels the functional flow and then back from indicator to source document.
